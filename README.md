# Rasmodium — экран загрузки

Экран загрузки для Garry's Mod: бренд, случайный сплэш, советы, прогресс
(`SetStatusChanged`, `SetFilesTotal` …) и фоновая музыка.

## Файлы

```
index.html   — сам экран загрузки
music.mp3    — фоновый трек
```

Клади `index.html` и `music.mp3` в одну папку — музыка подхватится сама,
никакие пути править не нужно.

## Музыка

* Скрипт сам перебирает список файлов (`TRACKS` в `index.html`) и включает
  первый найденный:
  `music.mp3` → `music/music.mp3` → `music/GTA_V.mp3` → `music.ogg` → `music/GTA_V.ogg`.
  Если переименовал трек — просто добавь новое имя в начало списка.
* Громкость — переменная `VOLUME` (по умолчанию `0.4`, диапазон `0.0`–`1.0`).
* Кнопка в правом верхнем углу или клавиша **M** — вкл/выкл звук.
* Если трек не найден, кнопка показывает `♪ NO MUSIC FILE`, а в консоль
  пишется, какие пути искали.
* Браузеры (и встроенный браузер GMod) могут блокировать автоплей до первого
  действия пользователя. Скрипт пробует запуск сам, повторяет попытки и
  включает музыку по первому клику/нажатию клавиши/возврату фокуса.

## Подключение в GMod

Залей папку на любой хостинг и укажи в конфиге сервера:

```
sv_loadingurl "https://твой-сайт/index.html"
```

Если хостинг требует имя `loading.html`, просто переименуй `index.html`
в `loading.html` и укажи это имя в `sv_loadingurl` — музыка продолжит работать.

## Локальная проверка

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Через 4 секунды без вызовов GMod-API включается демо-прогресс — удобно
проверить анимацию в обычном браузере.
